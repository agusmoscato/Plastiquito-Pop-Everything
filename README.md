# Plastiquito: builds de prueba

## 0.7.3 (la más nueva, para el playtest con personas)

- **Windows:** bajá `0.7.3/Plastiquito_0.7.3_windows.zip`, descomprimilo y hacé doble clic en `Plastiquito.exe`.
  También está el instalador `0.7.3/Plastiquito_0.7.3_setup.exe`.
- **Linux:** `0.7.3/Plastiquito_0.7.3_linux.zip`.
- Estas builds van **sin Steam**: el juego pregunta "¿Cómo te llamás?".
- `0.7.3/Plastiquito_0.7.3_steamtest.zip` es solo para el desarrollador (Steam encendido con el App ID 480 de prueba). **No repartir.**

Windows puede avisar que el programa no está firmado: "Más información" y después "Ejecutar de todas formas".

Versiones anteriores en `0.7.2/`, `0.7.1/`, `0.7.0/`, `0.6.1/`, `0.6.0/`, `0.5.0/`, `0.4.0/`, `0.3.1/` y `0.3.0/`.
